# 樱之屋数据源目录

为樱之屋提供数据源目录、版本信息和下载校验，支持独立更新。

本仓库仅维护索引元数据，不存放漫画、小说、图片、第三方脚本或用户凭据。应用从索引指定的原始发布地址获取脚本；目录中的待验证标记不代表阅读功能已可用。

本仓库原创内容采用 MIT 许可证。第三方脚本与站点内容不在此授权范围内，使用前须确认其授权和使用条件。

## 安装已通过样本检查的源

在樱之屋进入「我的 → 数据源」，把 HTTPS 索引地址改为：

```text
https://raw.githubusercontent.com/Yukilove0222/SakuraHouseSourceIndex/main/verified.json
```

保存并加载目录，然后逐项点击「安装」。这份目录仅包含 **10 个有阅读样本证据的普通脚本**：拷贝、热辣、GoDa、H-Comic、漫小肆、MYCOMIC、nhentai、再漫画（10月10日），以及禁漫、Picacg（10月12日，限制见上文）。每项保留固定上游提交与 SHA-256，拷贝仅收录普通单账号版本。

`index.json` 是 33 项完整目录，含未通过、待登录与未复测来源；`verified.json` 是上述日期的通过样本目录，不表示后续持续监测或全站可用。文库8由 App 内置，因此不在脚本安装目录中。轻书架保持暂停，不纳入此目录。

发布索引不会自动安装脚本；每台设备需要独立安装，或通过 App 支持的备份恢复。IPA 不携带第三方脚本、账号或会话。
